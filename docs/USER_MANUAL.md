# 基层人大代表信息管理系统 · 使用手册

> 本手册面向人大办工作人员与教学演示场景，按步骤操作即可完成全部功能演示。系统为演示环境：数据为固定种子模拟数据，仅保存在本机浏览器中。

## 一、访问方式

| 环境 | 网址 | 说明 |
|---|---|---|
| 本地开发 | http://localhost:5173/npc-deputy-system/ | 在项目文件夹执行 `npm run dev` 后访问 |
| 公网演示 | https://kji11111.github.io/npc-deputy-system/ | 推送到 GitHub 后自动部署；若内容未更新，按 `Ctrl+F5` 强制刷新 |

## 二、角色与权限一览

| 角色 | 进入方式 | 可见菜单 | 可以做什么 | 不能做什么 |
|---|---|---|---|---|
| 管理员（人大办） | 登录页「管理员」标签，一键进入 | 数据仪表盘、代表档案管理、活动管理、提案建议交办 | 档案增删改、活动增删改、审核交办、转送代表、再次交办、导出 CSV | —— |
| 人大代表 | 「人大代表」标签，下拉选择本人 | 我的档案、我的活动、我的提案 | 查看本人画像、提交建议、满意度评价 | 看不到他人数据，不能交办/转送 |
| 承办单位 | 「承办单位」标签，下拉选择单位 | 提案办理 | 受理、登记答复（推回人大办） | 看不到档案/活动，不能交办、不能转送 |

## 三、第一次使用（重要）

1. 打开上面的访问地址，进入登录页。
2. 先以任意角色进入系统（建议管理员）。
3. 点右上角 **头像/姓名 →「重置演示数据」**，在确认框中点「重置」。
4. 右上角再次点头像 →「退出登录」，回到登录页，按第十节的演示路径开始。

> 提示：浏览器里若存有旧版本数据，不先重置会看不到「待转送」等新状态。

【截图：顶栏“重置演示数据”菜单】

## 四、登录（三种角色）

1. **管理员**：切到「管理员」标签，点「以管理员身份进入」。
2. **人大代表**：切到「人大代表」标签，在下拉中搜索并选择代表（新增过的代表也会出现在这里），点「以代表身份进入」。
3. **承办单位**：切到「承办单位」标签，建议选择「镇村镇建设服务中心」（演示数据已保证该单位有件可办），点「以承办单位身份进入」。

## 五、数据仪表盘（仅管理员）

1. 查看顶部 4 个指标卡：代表总数、近一年活动、提案建议、办结率。
2. 查看四张图表：近 6 个月活动数量（按类型堆叠）、提案分类分布（环形图）、办理状态分布（含“待转送”）、履职积分 Top8。
3. 将鼠标悬停在图表上可看具体数值。

【截图：数据仪表盘】

## 六、代表档案管理（管理员操作；代表仅看本人）

1. **查询筛选**：顶部搜索框输入姓名/编号；右侧下拉按界别、镇街、连任情况筛选。
2. **新增代表**：点页头大按钮「**新增代表档案**」（或筛选栏「新增代表」）。带 * 为必填；「界别」「所属镇街」可下拉选择、**也可直接输入新值**；保存后系统提示“档案已新增，退出后可在登录页用该代表身份进入”。
3. **编辑**：操作列「编辑」，修改后保存。
4. **删除**：操作列「删除」→ 确认。仅移除档案，该代表的历史活动与建议记录保留。
5. **详情与履职画像**：操作列「详情」。上半部分为基本信息；中部为**五维雷达图**（活动参与 / 提案建议 / 学习培训 / 代表述职 / 联系群众）与履职积分（积分 = 活动×2 + 建议×3 + 培训 + 述职×5 + 联系群众×0.2）；下部两个页签列出其参加的活动与提出/附议的建议。
6. **导出 CSV**：点「导出 CSV」，下载当前筛选结果，Excel 可直接打开（中文不乱码）。

【截图：履职画像雷达图】【截图：新增代表表单】
## 七、活动管理（管理员维护；代表仅看本人参加）

1. **新建活动**：点「新建活动」，选择类型（调研视察 / 约见镇长 / 代表述职 / 学习培训），填写主题、日期、地点、组织单位，多选参与代表，填写活动纪要后保存。
2. **筛选**：按类型、状态、年份筛选，或关键词搜索。
3. **编辑 / 删除**：操作列对应按钮，删除需确认。
4. **详情**：查看参加代表名单与活动纪要。
5. **导出 CSV**：同档案页。

## 八、提案建议交办闭环（核心功能）

### 8.1 流程总览

```
待审核 →(人大办审核交办)→ 已交办 →(承办单位受理)→ 办理中
       →(承办单位登记答复)→ 待转送 →(人大办转送代表)→ 已答复
       →(领衔代表评价)→ 满意/基本满意 → 已评价（办结）
                    └→ 不满意 → 已退回 →(人大办再次交办)→ 已交办
```

### 8.2 状态与按钮对照表

| 当前状态 | 谁来推动 | 在哪里点什么 |
|---|---|---|
| 待审核 | 管理员 | 「审核交办」：弹窗中选承办单位与办理期限 |
| 已交办 | 承办单位 | 「受理」：确认后进入办理中 |
| 办理中 | 承办单位 | 「登记答复」：填写答复内容，提交后进入待转送 |
| 待转送 | 管理员 | 「转送代表」：确认后进入已答复 |
| 已答复 | 领衔代表 | 「满意度评价」：满意/基本满意 → 已评价（办结）；不满意 → 已退回 |
| 已退回 | 管理员 | 「再次交办」：清空上一轮答复与评价，重新交办 |

### 8.3 查看流转记录

任意状态下点「详情」，抽屉底部的时间线逐条显示：时间 · 操作者 · 动作（如“镇村镇建设服务中心受理”“承办单位提交答复，已推回人大办”“人大办已转送领衔代表，请评价”）。

### 8.4 提交建议

管理员点「新增登记」可代代表录入；人大代表点「提交建议」自行提交。新建议自动编号并进入「待审核」。

## 九、我的待办（顶栏 Badge）

| 角色 | 待办口径 |
|---|---|
| 管理员 | 待审核 + 待转送 + 已退回 |
| 承办单位 | 本单位的已交办 + 办理中 |
| 人大代表 | 本人领衔、已答复、尚未评价 |

点击顶栏「我的待办」→ 跳转到提案列表并自动按对应状态筛选；点蓝色提示条右侧 × 可返回全部。

## 十、完整演示路径：三角色走完一条建议（约 5 分钟）

| 步骤 | 角色 | 操作 | 预期结果 |
|---|---|---|---|
| 1 | 管理员 | 进入「提案建议交办」，找一条「待审核」件，点「审核交办」 | 弹窗中选承办单位（选“镇村镇建设服务中心”）与期限，状态变「已交办」 |
| 2 | 管理员 | 顶栏头像 →「退出登录」 | 回到登录页 |
| 3 | 承办单位 | 选「镇村镇建设服务中心」进入 | 仅见「提案办理」菜单，待办 Badge 有数字 |
| 4 | 承办单位 | 对该件点「受理」 | 状态变「办理中」，时间线新增“镇村镇建设服务中心受理” |
| 5 | 承办单位 | 点「登记答复」→ 填写答复内容 → 提交 | 状态变「待转送」，时间线显示“已推回人大办” |
| 6 | 承办单位 | 退出登录 | —— |
| 7 | 管理员 | 对该件点「转送代表」→ 确认 | 状态变「已答复」 |
| 8 | 管理员 | 退出登录 | —— |
| 9 | 人大代表 | 选择该件的领衔代表进入 →「我的提案」 | 待办提示 1 件待评价 |
| 10 | 人大代表 | 点「满意度评价」→ 选「满意」→ 提交 | 状态变「已评价」（办结） |
| 11 | 人大代表 | 点「详情」查看时间线 | 完整链路：提交→交办→受理→答复→推回→转送→评价 |
| 12（可选） | 代表/管理员 | 第 10 步改选「不满意」；再以管理员对「已退回」件点「再次交办」 | 清空上轮答复评价，状态回「已交办」，可继续演示 |

## 十一、常见问题（FAQ）

| 问题 | 说明 |
|---|---|
| 地址里出现 `#` 是不是出错了？ | 不是。系统使用 Hash 路由，例如 `…/#/proposals`，属正常现象；带 `#` 的链接刷新、分享都不会 404 |
| 我填的数据别人能看到吗？ | 看不到。全部数据保存在**本机浏览器** localStorage 中，仅本人可见；清浏览器缓存或点「重置演示数据」即恢复初始 |
| github.io 页面内容没更新？ | 部署需要 1~2 分钟；先在仓库 Actions 页确认绿勾，再按 `Ctrl+F5` 强制刷新 |
| 新增的代表在登录页找不到？ | 保存后需「退出登录」回到登录页；下拉来自系统数据，新增后一定存在 |
| 公网地址打开 404？ | 确认网址末尾为 `/npc-deputy-system/`；并确认仓库 Actions 部署成功、Settings → Pages 已选 GitHub Actions |
| 想知道某件建议办到哪一步了？ | 点「详情」查看流转时间线，每次状态变化都有记录 |
| 数据会不会被我改坏？ | 不会。随时点顶栏「重置演示数据」恢复初始演示数据 |
